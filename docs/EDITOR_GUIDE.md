# Let’s Play 內容編輯手冊

這份手冊依 0.3.1 主題的本機原生 WordPress 操作整理。免費 Cloudflare 私人後台尚未完成正式驗收；目前沒有交付正式管理登入網址。WordPress 儲存成功與更新公開 Pages 官網是兩個步驟，正式官網維持現況。

## 修改單一頁面

1. 登入後開啟「頁面」，選擇品牌、課程、教練、據點或合作頁面。
2. 在編輯畫布點選要修改的文字，直接輸入。需要選取內層區塊時，可使用「清單檢視」。
3. 按右上「儲存」，等候「頁面已更新」提示，再重新整理確認文字仍在。
4. 開啟前台頁面核對段落、電話與連結，再用未登入的視窗確認公開結果。
5. 誤改可先使用復原；儲存後可透過頁面的修訂版本還原。正式操作前應保留備份。

五個內容頁已實際測試「修改 → 儲存 → 重載 → 還原原文 → 儲存 → 重載」。首頁另有完整後台程序重啟及讀回證據。這些結果來自隔離本機，不代表私人雲端已通過相同流程。

## 修改全站頁首與頁尾

從「外觀 → 編輯器 → 區塊版面配置」進入範本組件：

| 要修改的內容 | 選取位置 | 檢查範圍 |
| --- | --- | --- |
| 導覽文字與連結 | 「頁首」中的「品牌頁首」 | 六個主要頁面，以及手機選單 |
| 品牌說明與頁尾聯絡資訊 | 「頁尾」中的「品牌頁尾」 | 六個主要頁面的底部 |

點選文字或導覽項目進行編輯，按「儲存」，看到「範本組件已更新」後重新開啟確認。共用組件會影響所有使用它的頁面；本次已分別驗證修改與還原在六頁前台可見。

## 首頁與更新主題

如果站內原本已有首頁，安裝及匯入主題會保留原設定。請至「設定 → 閱讀」，選擇靜態首頁「Let’s Play 桌球聯盟」，儲存後檢查根網址。

更新主題不會覆寫已編輯的頁面或已客製的範本組件。0.3.2 的新地圖按鈕文字適用新匯入內容；既有頁面請直接將兩處按鈕改成「蘆洲店地圖 ↗」與「林口桌球地圖 ↗」。不要刪除現有內容來強迫重新匯入。

## 內容確認與發布

北投總公司等待公布；新增教練履歷、照片、課綱、檢定、QA、優惠及 IG 等依[店家待補清單](CONTENT_REVIEW_20261125.md)核對。編輯者可先存草稿，未確認資料不自行補寫。

公開 Pages 的發布與回滾依[操作手冊](OPERATIONS.md)處理。品牌預覽和正式站分開；完成後台儲存不會自動讓目前的正式官網換版。
