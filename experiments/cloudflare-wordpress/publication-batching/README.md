# 私人 WordPress 發布合併候選

正式 playtt.tw 維持 Pages；使用者已決定繼續全 Cloudflare 免費後台研究，暫不切換後台。本目錄接續記憶體調查候選，不能獨立套用成正式環境。

## 問題與行為

舊發布器逐一重建每個編輯版本。連續樣式與導覽操作可能產生多個六頁重建工作，實測在開始發布回歸前等待清空就超過360秒。

新候選一次讀取最多32個最舊工作，在持有revision lease並核對每筆精確commit receipt後，合併連續已提交版本的變更。採用批次最後一個canonical快照，保留每個受影響的頁面與依序發生的撤回／重新發布；全站變更仍重建所有應公開頁面。未提交工作會中斷合併。新版本完整產生前保留原公開指標，不刪除舊工作；成功切換後，既有receipt流程才將舊工作標記superseded並清理。

若建置途中又有編輯，新的批次可以包含先前未完成的變更。只重用相同canonical版本的頁面產物；合併計畫改變時重設進度。這只影響Let’s Play單站DO alarm路徑，未更改上游Queue訊息的精確工作授權。
