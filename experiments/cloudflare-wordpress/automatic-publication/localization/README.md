# 繁體中文初始化

固定 WordPress7.1.4 官方 zh_TW 語言包，先核對 SHA256，再打包77個執行所需語言檔。原始翻譯來源與套件版本見建置程式。透過 WordPress 原生外掛上傳及啟用後，語言檔複製到 languages/，設定站台與目前管理員語系；停用並刪除初始化外掛後，翻譯會保留。

這是一次性部署工具，不包含於品牌主題，也不作為正式站常駐外掛。本機安裝、移除後繁中保留已驗證，遠端驗收另見證據。重新打包的ZIP時間戳不同，測試腳本的ZIP hash應使用本次建置輸出；固定官方來源hash不可更改。
